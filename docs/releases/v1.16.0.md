# v1.16.0 — Backtest integrity, consistent sizing, and research tools

Released 2026-10-24. Includes all changes since [v1.15.0](https://github.com/zachisit/july-backtester/releases/tag/v1.15.0), including the backtest-integrity epic and subsequent adversarial-review fixes.

## Upgrade and result compatibility

**Re-run affected backtests before comparing them with earlier results.** Entry eligibility, fills, stop exposure, short buying power, equity timing, and WFA/Monte Carlo verdicts have changed. Trade counts, allocations, costs, and reported metrics can move in either direction.

| Setting or behavior | v1.16.0 behavior | Compatibility option |
| --- | --- | --- |
| Entry triggering | `entry_trigger="edge"`: enter on a fresh transition into a long/short state. A persistent state does not re-enter after a stop or a missed capacity opportunity. | Set `entry_trigger="level"` for the former entry-eligibility policy. |
| Gap-through initial stops | `stop_gap_fill="open"`: use the worse open when a bar opens beyond the stop. | Set `stop_gap_fill="level"` for level fills. Armed trailing stops keep their separate `stop_gap_fill_armed_trail` policy. |
| Fill-bar stops | `entry_bar_stop_check=True`: check the initial stop on the fill bar under open execution. | Set `entry_bar_stop_check=False` to disable that check. |
| Equity-short collateral | `short_margin_requirement=0.5` reserves buying power until cover. | Set `0.0` for the former unreserved-collateral policy. |
| Indicator warm-up | `pit_warmup_days=400` now fetches pre-start history for symbols and dependencies; execution remains inside the requested window. | Set `pit_warmup_days=0` to disable the additional history. |
| Monte Carlo score | The displayed score/verdict uses the new edge and drawdown-realism tests. | `mc_score_legacy` / `mc_verdict_legacy` remain available for comparison. |

Use the pinned requirements in a fresh environment; validation uses Python 3.12. `ft-pandas-ta==0.3.16` replaces the unavailable `pandas-ta` pin while retaining the `pandas_ta` import. SciPy and Seaborn are explicitly declared.

The private Parquet data submodule and dataset-maintenance/export scripts have been removed from this repository. Supply your own per-symbol Parquet files through `parquet_data_dir` / `--parquet-dir`. The optional private-strategy submodule remains available.

## Execution and position sizing

- Honor coarse gap-through stops and fill-bar stops, including intraday refinement when available. Record portfolio equity after the bar’s fills and exits.
- Use prior-bar ADV for opening entries. Futures shorts now apply the liquidity cap and adverse entry impact, account for both impact legs, and budget margin from the actual fill.
- Measure futures-long heat using its known stop exposure. Both futures directions recheck final fill risk before committing cash or margin and register that exposure for later entries.
- Freeze Kelly history before an opening fill bar, excluding outcomes learned later in that bar; closing entries can use completed same-bar outcomes.
- Route all sizing methods through the shared sizing entry point. Equity and futures shorts honor the configured method and per-signal size multiplier.
- Resolve percentage, ATR, trailing, points, and signal-bar stop inputs consistently across sizing paths. Equity risk sizing supports fractional shares and a notional ceiling; contract caps and integer rounding apply to futures.
- Report missing stop inputs, ATR proxies, caps, cash/margin reductions, ADV caps, and heat rejections once per run, including zero-trade runs. Reports count conditions rather than unique entries.
- Liquidate delisted positions inside the simulation loop, release their capacity, prevent post-delisting re-entry, handle index time zones, and avoid funding an opening order with a later Close. Preserve exit fees and position-size metadata.
- Give seeded entry priority a reproducible shuffle on each bar. Preserve hold-state shorts through their actual cover signal. Decline tiny equity-short entries consistently with longs.

## Statistical validation and reproducibility

- Measure WFA IS/OOS performance on each equity window and annualize over its duration. Include the last day’s trades and intraday equity.
- Treat empty or undersized rolling folds as unavailable rather than successful; handle anchored history and exclude N/A folds from scoring.
- MC Score v2 adds a bootstrap edge test and compares closed-trade drawdown with the same drawdown definition. Block sampling also applies to the edge test when selected.
- Add `random_seed` / `--seed` for repeatable MC, bootstrap and noise. Seed components remain distinct, and runtime settings are propagated to spawned workers.

## Point-in-time universes and data quality

- Resolve dated PIT members to Parquet security IDs so live ticker reuse cannot substitute for a delisted company. Abort unresolved or ambiguous mappings; preserve unquoted ticker strings such as `ON`.
- Resolve retired tickers and explicit overrides through corpus rename metadata. Rebuild span indexes when the corpus changes, refuse distinct-security bare-ticker collisions, and share the Parquet directory default between price and universe readers.
- Discover S3-synced PIT rosters beside the price corpus after explicit config/environment overrides. Universe selection, membership schedules and forced exits use the same source.
- Skip incomplete or malformed automatic rosters and abort if no valid complete source remains. An explicitly selected source can retain missing years with warnings; malformed explicit files abort. An unpublished current-year file is optional, with opening membership carried from the last available roster. Normalize quoted/unquoted change dates and require canonical date strings.
- Keep short-lived names in survivorship-aware universes while retaining warm-up history; plain universes retain their minimum-bar policy. Emit skipped/kept-symbol diagnostics.
- Detect zero and other non-positive OHLC prices, charge an affected bar once, and continue missing-bars demerits through 60% missing coverage with a 30-point cap. The CHECK 5/6 integer casts remain in place.
- Retry Polygon 429/5xx responses, honor backoff, avoid caching partial pagination and write fetch-failure diagnostics. Yahoo includes the requested end-date bar.

## CLI, reporting, and installation

- Add `max_workers` / `--workers` to cap simulation processes.
- Honor `verbose_output`, `--verbose`, and `--no-verbose` consistently, including spawned workers.
- Account for zero-trade and errored simulations instead of silently omitting them; retain end-of-run diagnostics.
- Give each strategy/parameter/stop combination a distinct name and metadata. Sensitivity output reports one verdict per portfolio, strategy and stop configuration, including fractional percentage stops, ATR caps and trailing floors.
- Sanitize output filenames across CSV, chart and PDF artifacts, including Windows-illegal characters and colliding labels.

## Research tools

- Add `scripts/pattern_scan.py` for triangle, rectangle and inverse-H&S geometry, historical replay, per-family controls, HTML contact sheets and JSON parameters/coverage/tolerance provenance. Malformed symbols are isolated, Finviz report labels redact credentials, common share classes preserve their identity, and charts retain the entire detected base.
- Add `scripts/build_us_universe.py` to generate a dated local liquidity cache. Security descriptions take precedence over ambiguous suffix rules; preferred issues are excluded, and up to the last 20 available price bars determine dollar ADV (at least 10 closing-price rows are required). If no prices are scored, the existing cache is preserved; a partially covered run records its coverage in metadata. Generated snapshots are ignored by Git.
- Add the Pine chart-level companion with configurable confirm alerts and bounded drawing coordinates/counts. Scoring/continuation convention reconciliation is separately tracked in #383; Pine validation in this release is source review rather than compilation.
- Add gap-proximity, dead-money, annual-return, leverage and volatility diagnostics, plus a source-derived data-quality cast census. The census detects the current cap, reports full gate deltas, and exits promptly on initialization errors. Offline tests compare one- and multiple-worker output.

## Verification

- Full pytest suite, including slow tests: **3,555 passed, 6 skipped, 11 expected failures** on the release code.
- Every recently merged review item received a fresh adversarial sub-agent review, regression fixes, a posted review comment, a full-suite run and successful required CI checks before merge.
- Shared subprocess wrappers enforce spawn-safe execution, UTF-8 decoding, timeouts and positive evidence that the intended work ran. Mutation checks cover sizing, stop ladders, heat, density charges and wrapper guards; the audit requires green controls and restores source bytes.
- Frozen scanner bars reproduce the review tape and pin unchanged default levels/scores, MDLZ’s whole-base floor veto and XEL’s valid alternative floor. Offline CLI tests exercise replay, rendering, JSON, malformed weekly input and redaction.
